# hospital_network_simulation

This is a lab to configure a hospital network in Cisco Packet Tracer.

Read the guide at [Hospital Network Simulation](https://sagedemage.github.io/hospital_network_simulation/).

## Commands

Install all dependencies
```
pnpm install
```

Start the website
```
pnpm dev
```

Build the website
```
pnpm build
```

Preview the built website
```
pnpm preview
```
